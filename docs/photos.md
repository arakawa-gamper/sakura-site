# 写真の差し替え一覧

`public/images/` 内の仮画像を、**同じファイル名**の写真で上書きすると差し替わります。
仮画像の左上に、どの写真を入れる場所かが書いてあります。

## 撮影のコツ

黒基調のデザインなので、**暗めの背景で、肉や鍋に光が当たっている写真**が最も映えます。
夜の店内照明より、窓際の自然光や、料理だけに当てたライトで撮ると霜降りがきれいに写ります。
湯気・卵をくぐらせる瞬間・鍋から肉を持ち上げる瞬間など、「動き」のある写真があると一気に高級感が出ます。

予算をかけられるなら、プロのカメラマンに `hero.jpg`・`concept.jpg`・`banquet.jpg` の3枚だけでも依頼するのがおすすめです。

## アップロード前に

- ファイル名は半角英数字で、下の表と完全に同じにしてください（大文字・小文字も区別されます）。
- 形式は JPG。1枚あたり **500KB 以下** が目安です。大きい場合は [Squoosh](https://squoosh.app/) などで圧縮してください（画質 75〜80% で十分きれいです）。
- サイズは表の数値以上であれば、縦横比が多少違っても自動で切り抜いて表示されます。
